# MCP OAuth 2.1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the bearer-only auth on `/api/mcp` with full OAuth 2.1 + Dynamic Client Registration so claude.ai's custom-connector UI can connect.

**Architecture:** Add 5 OAuth endpoints (2 metadata, register, authorize, token) plus 3 Supabase tables (`mcp_oauth_clients`, `mcp_oauth_codes`, `mcp_oauth_tokens`). Replace the bearer guard in `/api/mcp` with a token-table lookup. Auto-approve consent if Supabase session matches `MCP_OWNER_USER_ID`. Tokens are opaque random strings (not JWTs).

**Tech Stack:** Next.js 16 App Router, TypeScript, Supabase (service role), `@modelcontextprotocol/sdk` types only (we don't use its Express router), `zod`, `vitest`.

**Design doc:** [`2026-05-04-mcp-oauth-design.md`](./2026-05-04-mcp-oauth-design.md)

**Spec:** MCP Authorization [2025-06-18](https://modelcontextprotocol.io/specification/2025-06-18/basic/authorization)

**Step 3: Implement**

```typescript
import { createHash, timingSafeEqual } from 'node:crypto'

export function verifyPkceS256(verifier: string, challenge: string): boolean {
  if (verifier.length < 43 || verifier.length > 128) return false
  const computed = createHash('sha256').update(verifier).digest('base64url')
  const a = Buffer.from(computed)
  const b = Buffer.from(challenge)
  if (a.length !== b.length) return false
  return timingSafeEqual(a, b)
}
```

### Task 10: `/api/oauth/authorize`

**Files:**
- Create: `app/api/oauth/authorize/route.ts`

**Spec (GET only):**

Query params (all required unless noted):
- `response_type=code` (validate exact)
- `client_id`
- `redirect_uri`
- `code_challenge`
- `code_challenge_method=S256` (validate exact)
- `state` (optional, echoed back)
- `scope` (optional, space-separated; we ignore semantically but record it)
- `resource` (RFC 8707; expected, but tolerate absent)

Logic:

1. Validate all params. On any failure → 400 JSON `{ error: 'invalid_request', error_description: '...' }`. Do NOT redirect.
2. Look up client. Unknown → 400 `{ error: 'invalid_client' }`.
3. Verify `redirect_uri` is in `client.redirect_uris`. Mismatch → 400 `{ error: 'invalid_request' }`.
4. Read Supabase session via `lib/supabase/server.ts createClient()`.
5. If no session: 302 to `/login?return_to=<this full URL urlencoded>`.
6. If session.user.id !== `MCP_OWNER_USER_ID`: 403 `{ error: 'access_denied' }`.
7. Else (authorized): call `createCode` with `client_id`, `user_id`, `redirect_uri`, `code_challenge`, `code_challenge_method`, `resource`, `scopes`. 302 to `${redirect_uri}?code=<code>&state=<state>`.

**Tests** (handler-level, with a fake Supabase server client + fake codes store):
1. Missing `response_type` → 400.
2. Unknown `client_id` → 400.
3. Mismatched `redirect_uri` → 400.
4. No session → 302 to `/login?return_to=...` (verify the encoded URL round-trips).
5. Wrong user → 403.
6. Happy path → 302 to `redirect_uri` with `code` + `state` params; verify codes store was called with the right inputs.

### Task 11: `/api/oauth/token`

**Files:**
- Create: `app/api/oauth/token/route.ts`

**Spec (POST only, `application/x-www-form-urlencoded` per OAuth 2.1):**

Required form fields per grant type:
- `grant_type=authorization_code`: `code`, `code_verifier`, `redirect_uri`, `client_id`, optional `resource`
- `grant_type=refresh_token`: `refresh_token`, `client_id`, optional `resource`, optional `scope`

Logic — `authorization_code`:
1. Look up client by `client_id`. Unknown → 400 `invalid_client`.
2. `consumeCode(code)`. null → 400 `invalid_grant` ("expired or already used").

4. `verifyPkceS256(code_verifier, row.code_challenge)`. False → 400 `invalid_grant`.
5. If `resource` provided in token request, must match `row.resource`. Mismatch → 400 `invalid_target`.
6. `issueTokens({ client_id, user_id: row.user_id, resource: row.resource, scopes: row.scopes })`. Return 200 JSON: `{ access_token, refresh_token, token_type: 'Bearer', expires_in: 3600, scope: scopes.join(' ') }`.

Logic — `refresh_token`:
1. `rotateFromRefresh(refresh_token)` → if null → 400 `invalid_grant`.
2. Return new pair in same shape.

Errors:
- Missing `grant_type` → 400 `invalid_request`.
- Unsupported `grant_type` → 400 `unsupported_grant_type`.
- All responses include `Cache-Control: no-store`.

```typescript
// lib/mcp/oauth/verify.ts
import type { TokenRow } from './tokensStore'

export type AuthInfo = { user_id: string; client_id: string; scopes: string[]; resource: string | null }

export async function verifyAccessToken(
  rawToken: string,
  expectedResource: string,
  deps: { findByAccessToken: (t: string) => Promise<TokenRow | null> },
): Promise<AuthInfo | null> {
  if (!rawToken) return null
  const row = await deps.findByAccessToken(rawToken)
  if (!row) return null
  if (row.revoked_at) return null
  if (new Date(row.expires_at).getTime() <= Date.now()) return null
  if (row.resource && row.resource !== expectedResource) return null
  return { user_id: row.user_id, client_id: row.client_id, scopes: row.scopes ?? [], resource: row.resource }
}
```

**Step 3: Modify `app/api/mcp/route.ts`**

Replace the existing `isAuthorized` import + check. New flow:

```typescript
import { NextResponse } from 'next/server'
import { createAdminClient } from '@/lib/supabase/admin'
import { mcpHandler } from '@/lib/mcp/server'
import { verifyAccessToken } from '@/lib/mcp/oauth/verify'
import { findByAccessToken } from '@/lib/mcp/oauth/tokensStore'

function originOf(r: Request) { const u = new URL(r.url); return `${u.protocol}//${u.host}` }

function unauthorized(resourceMetadataUrl: string) {
  return new NextResponse(JSON.stringify({ error: 'unauthorized' }), {
    status: 401,
    headers: {
      'content-type': 'application/json',
      'www-authenticate': `Bearer resource_metadata="${resourceMetadataUrl}"`,
    },
  })
}

async function guarded(request: Request) {
  const header = request.headers.get('authorization')
  const resource = `${originOf(request)}/api/mcp`
  const metadataUrl = `${originOf(request)}/.well-known/oauth-protected-resource`

  if (!header?.startsWith('Bearer ')) return unauthorized(metadataUrl)
  const token = header.slice(7)

  const supabase = createAdminClient()
  const auth = await verifyAccessToken(token, resource, {
    findByAccessToken: (t) => findByAccessToken(t, { getClient: () => supabase }),
  })
  if (!auth) return unauthorized(metadataUrl)

  return mcpHandler(request)
}

export const GET = guarded
export const POST = guarded
export const DELETE = guarded
```
